# ScaleBridge — web brand / Identité web

Blue ink and mineral teal, original bridge symbol and clear labels. SVG sources, transparent PNG variants, avatars, favicons and social artwork live in `assets/`. Colours and radii are defined in `assets/design-tokens.json`; the web shares light/dark/system appearance through `theme.css` and `theme.js`.

Keep at least one quarter of the symbol width clear around the logo. Do not stretch or add effects. Choose the contrasting light/dark/monochrome variant. SVG logos reference installed sans/Arial; no font files are included.

The twelve Lucide icons have explicit roles and reasons in `assets/icon-usage.json`. Import: file-up; column mapping: columns-3; review: clipboard-check; export: file-down; local storage: hard-drive; deletion: trash-2. Decorative icons use `aria-hidden` and actions retain visible text. Full third-party notices are included.

This web edition contains fictional demonstrations and illustrative captures only. It does not include or claim to distribute the Android implementation. Original brand files use MIT; Lucide icons retain their own notices. `brand.html` presents the variants and downloadable public kit.
