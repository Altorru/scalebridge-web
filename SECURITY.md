# Security / Sécurité

Report a suspected security issue privately to contact@hugoviaud.fr with page, browser, reproduction steps and impact using synthetic data only. Do not publish live credentials, personal records or health files in an issue. No response-time or audit certification is claimed.

This repository is a static website and fixed demo: no backend, authentication, payment, file processing service or native Android build. Production hosting, logs, backups and retention are managed separately. Do not assume a localStorage theme preference is a secure data store. Keep real health files out of the demo and keep third-party notices when redistributing assets.
